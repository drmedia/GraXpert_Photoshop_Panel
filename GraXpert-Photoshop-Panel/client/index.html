시작하기

  1. Photoshop에서 처리할 RGB 픽셀 레이어를 선택합니다.
  2. 설정에서 GraXpert 실행 파일 경로와 GPU 사용 여부를 확인합니다.
  3. Background Extraction 또는 Noise Reduction 탭을 선택해 실행합니다.

결과는 원본을 변경하지 않고, 처리 시작 시 선택했던 레이어 바로 위에 새 레이어로 추가됩니다.

Background Extraction

AI 자동은 GraXpert가 배경 Gradient를 자동 분석합니다. 처음 사용할 때 권장합니다.

Sample Point는 사용자가 확인한 배경 위치로 Gradient를 계산합니다. 자동 결과가 은하나 성운까지 어둡게 만들 때 사용하세요.

  • [자동 생성]으로 초기 Point를 만듭니다.
  • [Gradient Editor 열기]에서 Point를 추가·삭제·이동합니다.
  • 초록색 Point만 계산에 사용됩니다. 주황색과 빨간색은 위치 또는 품질 설정을 조정하세요.
  • 빠른 미리보기로 원본과 비교한 뒤 Photoshop에 적용해 전체 해상도 결과를 생성합니다.

선택 영역과 레이어 마스크

Background Extraction: 선택 영역이나 현재 레이어 마스크는 Sample Point 분석 범위로만 사용합니다. Gradient 결과에는 마스크를 만들지 않습니다.

Noise Reduction: Photoshop 선택 영역을 우선 결과 마스크로 사용하며, 선택 영역이 없으면 현재 레이어 마스크를 복사합니다.

상세 설정

  • Smoothing: 배경 모델을 부드럽게 만드는 정도이며 기본값은 0.50입니다.
  • Correction: 일반적인 광해는 Subtraction, 비네팅은 Division을 비교합니다.
  • Background Model: 선택하면 전체 해상도 모델을 숨김 레이어로 추가합니다.
  • Denoise Strength: 기본값 0.50에서 시작합니다.
  • Batch Size: 기본값 4이며 GPU 메모리 부족 시 2 또는 1로 낮춥니다.

문제가 있을 때

  • 처리 중에는 패널, 원본 문서와 Gradient Editor를 닫지 마세요.
  • 처리 중 선택 레이어, 문서 이름 또는 캔버스 크기를 변경하지 마세요.
  • GraXpert를 찾지 못하면 설정에서 GraXpert.exe를 다시 선택합니다.
  • 설치 문제가 있으면 Photoshop을 종료하고 Diagnose_Install.bat를 실행합니다.
